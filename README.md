# Luxury Jewellery Sales Dashboard

## About the Project

This is an Excel-based sales analysis project where I cleaned jewellery transaction data and built an interactive dashboard to understand sales performance.

The dashboard helps analyze sales by category, customer type, jewellery item, payment method, and month.

## Tools Used

- Microsoft Excel
- Power Query
- PivotTables
- PivotCharts
- Slicers
- Excel formulas

## Dataset

The dataset contains 20,000 cleaned jewellery transactions from 2020–2021.

It includes:

- Gold, Silver and Diamond categories
- Different jewellery item types
- Regular, Walk-In and Wedding Order customers
- Cash, Card and Installment payment methods

## What I Worked On

### Data Cleaning

I used Excel and Power Query to:

- Remove duplicate Transaction IDs
- Identify missing Weight values
- Standardize customer-type values
- Check unusual Price values
- Create a Weight Status field
- Validate the cleaned data before analysis

### Dashboard

The dashboard includes:

- Total Sales
- Total Transactions
- Average Transaction Value
- Weight Sold
- Average Price per Gram
- Monthly Sales Trend
- Sales by Category
- Sales by Customer Type
- Sales by Item Type
- Sales by Payment Method

I also added slicers for Year, Month, Category, Customer Type and Payment Method so the dashboard can be filtered interactively.

## Key Insights

- Gold and Diamond together contributed around 99.7% of total sales.
- Walk-In customers contributed around 45.8% of total sales.
- The top three jewellery items generated around 62% of total sales.
- Cash accounted for around 54.7% of total sales.
- Sales increased by around 1.8% from 2020 to 2021.
- Total sales were approximately ₹3.58 billion.

## Data Quality Checks

During the cleaning process, I found:

- 95 duplicate Transaction IDs, which were removed.
- 380 records with missing Weight values.
- 1 transaction with a zero Price, which was flagged for review.

## What I Learned

This project helped me practice working with Power Query, PivotTables, PivotCharts, Excel formulas, slicers, KPI reporting and business-oriented data analysis.

It also helped me understand how to move from raw data → cleaning → analysis → visualization → business insights.
